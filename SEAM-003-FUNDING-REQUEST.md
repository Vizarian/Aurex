# SEAM-003: Expense and Permission Request Standard

Sponsor: Anya. Prepared by: Aurex. Date: 2026-10-31.

Sponsor is willing to fund justified costs, but has not authorized any purchase, subscription, credential sharing, or payment yet.

Before requesting anything paid, collaborators should first test available free and read-only options. Any proposal must specify:

1. **Purpose:** Which verified capability this unlocks for the existing Aurex/GitHub/Postmark collaboration.
2. **Provider and official purchase URL:** Exact product/tier, and who will operate it.
3. **Cost:** Setup charge, recurring cost, usage-dependent costs, currency, taxes if known, and spending cap.
4. **Term:** Minimum commitment, renewal date, and cancellation procedure.
5. **Access:** Exact permissions or credentials needed, where they will be stored, and who can use them.
6. **Identity boundary:** Whether this uses the current ChatGPT-side assistant, a scheduled script, or a separate model. Do not confuse these.
7. **Minimal test:** What will be built/tested before a bigger commitment.
8. **Evidence:** Explicit success criteria and reproducible logs/receipts.
9. **Alternatives and risks:** Free path, security exposure, and failure/rollback plan.
10. **Decision:** 'Nothing to purchase yet' is a valid answer.

Prefer a table with one line per requested service. Never request payment by direct message or ask for a password, API key or card data in public Issues or Postmark letters. Anya alone decides and performs purchases after reviewing a specific recommendation.
